NIMBY Timetable Toolkit 1.8.0

自动铺轨
- 新增起点、多个途经站、终点的顺序规划，最多 20 站，支持调整顺序和移除站点。
- 各区间分别检查并说明失败原因；可移除相关站点后重新预览。移除只影响方案，不删除游戏内车站。
- 有失败区间时禁止写入；全部通过后统一生成新测试副本。
- 修复删除/重建车站留下空槽时，错误提示无法确定轨道表结束位置的问题。
- 识别车站有效对象与空槽，保留原始索引和数据；不放宽轨道分配器及未知结构保护。
- 修复途经点靠近底图节点时产生极短碎线的问题。

线路图导出
- 增加 JSON 导出，包含当前勾选线路、站序、相关车站原始经纬度和绘图设置。
- 可设置并记住 SVG / JSON 导出文件夹，支持恢复默认，同名文件不覆盖。
- JSON 是工具箱线路图数据，不是游戏时刻表导出、GeoJSON 或存档。
- 导出失败显示实际错误，不再误报已触发下载。

升级说明
- 继续提供 Windows x64 零基础 EXE 包，包含 Python 和 Node.js，无需另行安装，不弹出终端。
- 旧版可通过软件内“检查更新”升级；下载包进行 SHA-256 和文件清单校验，升级前备份程序文件。
- 设置、存档及用户导出文件不属于升级覆盖范围。
- 自动铺轨仍为实验功能：仅生成待建双轨，站台接轨和信号须人工完成。务必保存游戏进度，加载新副本检查，不覆盖正式存档。
