NIMBY Rails 运营工作台 1.7.0

新用户：下载 NIMBY-Timetable-Toolkit-portable-v1.7.0.zip，完整解压，双击 NIMBYToolkit.exe。
不要下载 GitHub 自动生成的 Source code ZIP 来代替免安装包。
无需安装 Python/Node.js，无需管理员权限；包含“先看这里.txt”和“故障诊断.exe”。

已有用户升级
- 已有“检查更新”按钮的官方便携版：检查更新 → 下载并重启更新。
- 旧版可能缓存检查结果最多 6 小时；点击“检查更新”可立即重新检查。
- 安装仍需用户确认，不会静默替换正在运行的工具；Git 源码目录不自动覆盖。
- 无更新按钮的老版本请下载完整 ZIP，解压至新文件夹。
- 升级后保留用户设置；更新器不处理游戏存档。操作存档前仍请自行备份。
- 新版入口切换至内置运行库，旧版 Python 不会被卸载或修改。

新增与改进
1. Windows x64 零基础 EXE 包：内置 Python、Node.js、桌面组件；隐藏终端启动，中文诊断报告。
2. 自动铺轨（实验）：选两站或输入经纬度，读取游戏本地矢量底图寻路；自动发现 GeoJSON。
3. 地面/桥梁/隧道可分别选中速、高速、电车内置轨道，默认中速；首次四步教学和彩色预览。
4. 新副本写入前检查路径、冲突、重复和预览指纹，写后回读；保留玩家已续存副本的清理保护。
5. ORM 按需地图缓存、容量管理、离线模式与随游戏启动的静默服务。
6. 游戏 1.19.10 写入版本护栏、过期预览检查，继续保留线路工作台、时刻表与教程功能。

已知限制，请先阅读
- 支持 Windows 10/11 x64（Intel/AMD）。原生窗口依赖 WebView2，缺少时可能退回浏览器。
- EXE 暂未签名，可能被 SmartScreen/智能应用控制拦截；请勿关闭安全防护。
- 自动铺轨仍是实验功能，不保证任意两站有连续可用路线，也不支持任意工坊轨道。
- 只生成待建双轨蓝图，不自动连接既有站台/道岔、不配置轨道信号。
- Vandry–Dessane 原型曾由用户确认加载成功；新电车、隧道、混合速度的游戏加载/建造/行车仍待验收。
- 底图桥隧标记不等于地形高程；加载新副本后暂停检查，再小范围试建和手动接轨。
- 单段自动寻路有距离、瓦片和资源上限，长线请分段。详细限制见包内 docs/AUTOTRACK.md。
