NIMBY Timetable Toolkit 1.8.2

线路图修复
- 修正常规布局中独立线路几何重合、颜色互相覆盖的问题。GO Barrie / Richmond Hill、Kitchener / Milton 等线路分别安排空间，不再被压成同一条线。
- 移动整段线路时同步处理弯道锚点；真正共用的节点保留，入口分开连接。普通站与无关线路之间增加避让检查。
- 同一线路分叉后汇合的不同路径分别保留。例如同时选择经 Hamilton 和直接至 West Harbour 的源线路时，两条连接不再叠成一条。
- 保留源线路站序、站点 ID 和全部连接。旧总线与新分支同时存在时不会擅自删除旧数据；不把普通交叉当成换乘。
- 继续保留同线路分支的共线区间合并功能，不恢复为重复绘制多条主干。

标注与性能
- 改善 Union 附近的线路间距和站名安排，站名引线优先避让其他线路和标注。
- 必要时适度扩大布局；仍有引线障碍时显示独立提示，线路图 JSON 新增 label_leader_crossings 字段，不与站名框冲突数混为一谈。
- 线路避让结果在同次绘图的标注调整中复用，减少重复计算。
- 增加独立线路重叠、弯道锚点一致性、分叉后汇合路径和 GO 普通站误落到无关线路上的回归测试。

升级说明
- 继续提供 Windows x64 免安装 EXE 包，内置 Python、Node.js 和桌面组件。
- 已有更新按钮的便携版可点击“检查更新”，确认后下载并重启；手动检查不受启动检查的 6 小时缓存限制。
- 更新校验 ZIP SHA-256 与逐文件清单；不覆盖游戏存档、个人设置或导出数据。
- 本版修复的是常规线网图布局；网格布局仍保留原有水平 / 垂直连线方式。自动示意图并非地理测绘图，也不能代替游戏内轨道或运营核验。
