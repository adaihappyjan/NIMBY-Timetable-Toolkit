NIMBY Timetable Toolkit 1.8.7

界面样式焕新
- 整合新的深色主题，统一字体、字号、间距、按钮、表单、卡片、提示及键盘焦点样式。
- 侧栏按开始、分析与地图、建设与排班、模组、维护与关于分组；导航使用 SVG 图标，快捷功能搜索同步显示图标。
- 总览更换线路插画，整理自动铺轨与线路工作台的重复控件样式，并适配窄窗口导航。

发布范围
- 延续 1.8.6 的时刻表、自动铺轨、线路图、ORM 缓存、文件跟进和副本清理功能；本次不改变存档写入算法与安全校验。
- 本次正式包不包含或启用 3D 功能，不收录 experiments 实验目录、3D 注入组件或 AI 本地配置。

下一版本预告
2.0.0 beta 3D 版本即将释出。
3D 功能正在独立开发，具体能力、兼容范围及使用方式以 beta 发布说明为准；本预告不表示功能已通过验收，不提供或自动下载任何 3D 内容。
稳定版自动更新不会安装预发布版，1.8.7 用户可以继续使用现有工具箱。

升级方法
- Windows x64 完整 EXE 包内置 Python、Node.js 和桌面组件；解压后运行 NIMBYToolkit.exe，无需自行安装运行库，不弹出黑色终端窗口。
- 已有便携版点击“检查更新”，确认后下载并重启。更新校验 ZIP SHA-256 和逐文件清单，不覆盖游戏存档及个人设置。
- Git 源码工作区不会被自动更新器覆盖。更新前请保存未完成工作并关闭多余工具箱窗口。
- 存档修改仍只创建新副本；生成结果仍须在游戏内检查，代码测试不等于游戏内验收。
