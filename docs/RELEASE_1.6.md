## 更新方法

使用便携版右上角“检查更新”，确认后选择“下载并重启更新”。启动时可自动检查，但不会静默安装。Git 源码目录不允许覆盖更新；没有更新按钮的早期版本需先手动下载一次新版便携包。

下载 `NIMBY-Timetable-Toolkit-portable-v1.6.0.zip`，不要将 GitHub 自动生成的 Source code ZIP 当成便携安装包。保留用户配置和正式游戏存档；更新包只管理工具程序文件。
