# 自动铺轨早期验收记录

正式 1.7.0 发布说明见 RELEASE_1.7.0.txt；以下保留为发布前研究记录，不代表所有工程已游戏验收。

## 新功能

- 两站自动寻路：读取当前存档站点及游戏本地矢量铁路，支持经纬度备用输入。
- 三种内置轨道，中速默认；地面、桥梁、隧道分别配置速度类型。
- 自动发现本地 GeoJSON、Steam 地图库；独立后台解码，无终端窗口。
- 首次四步教学，随时重看，已读状态持久保存。
- 离线彩色预览、吸附距离、端部避让、重复检查、预览指纹和写后回读。
- 只生成新副本，自动清理保护玩家已续存的副本。

## 发布前说明

本次为实验功能：不自动连接既有站台/道岔，不生成信号，不保证任意两站必有路，
不支持任意工坊轨道模板。需要 Node.js 22+ 进行自动底图读取；1.7.0 EXE 包已内置。

新增电车/隧道/混合速度的游戏验收尚未完成，以实验功能发布，必须在说明中明确限制。
发布需要运行完整测试与便携包校验，然后发布正式 GitHub Release 和 SHA256SUMS。
仅推送源码不会使旧版收到自动更新；自动更新器只检查正式 Release。
这些测试未改动正式游戏存档。

## 本地核验

- Vandry–Dessane：54 个瓦片，路线约 7.17 公里；避让后生成约 6.88 公里、78 节点的双轨副本。
- Toronto Union–Bloor：铁路寻路约 6.47 公里，两端吸附约 1.3 / 3.0 米。
- McGill–Édouard-Montpetit：自动模式回退到共同轻轨网络，约 3.20 公里；两端吸附约 73.5 / 16.3 米，并显示回退警告。
- 完整 Python / 前端状态测试、便携包清单与更新器解包校验通过。
- 首次教学、教学记忆、自动读取、预览、新副本写入已做独立测试界面验收；不代表游戏内工程验收。
