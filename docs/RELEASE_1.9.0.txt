NIMBY Timetable Toolkit 1.9.0 — English-first, bilingual interface

Interface and documentation
- English is now the default; Simplified Chinese is available in the header.
- The language choice survives application restarts. Changing it asks for confirmation before reloading; finish active tasks and save drafts first.
- Bundled offline language resources cover navigation, tutorials, forms, map labels and diagnostic messages.
- Player-defined names, paths, IDs and game data remain unchanged.
- English README, quick-start TXT, user guide and Diagnostics.exe entry point; Chinese instructions remain available.

Existing features
- Retains timetable editing, automatic track laying, avoidance, route maps, local map caching, file following and copy cleanup.
- Save writes still create new copies. Structural verification is not in-game acceptance; load and inspect every generated save.
- Experimental projects and local development files are not included.

Coming next
2.0.0 beta with 3D features is coming soon, developed separately.
This release does not contain or enable 3D, injection components or experimental projects.
The announcement does not download anything. Stable updates do not install prereleases.

Updating
Use Check for updates, then confirm Download update and restart.
The Windows x64 portable ZIP includes Python, Node.js and desktop components.
SHA-256 and individual files are verified. Game saves and personal settings are retained.
Git source checkouts must update through Git rather than the portable updater.
