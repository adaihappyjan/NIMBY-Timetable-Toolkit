NIMBY Timetable Toolkit 1.8.1

线路图与分支网络
- 新增都市地铁、铁路总览两种线网图版式，以及水平 / 垂直网格布局。
- 换乘站提供大圆和胶囊形标记；缺失坐标不画虚构连线，同名不同 ID 的站点不擅自合并。
- 同线路分支合并不再限于 REM：结合名称、编号、颜色、共用区间与端点自动识别，并支持手动指定同组、保持独立及恢复自动识别。
- 同组共用相邻站间只画一条，普通站不误标为分支间换乘；不同分支的原始站序仍保留。
- 自动识别是基于导出数据的推断，无法代表游戏正式线路关系；仅共用起点不足以合并。跳站快车的物理轨道不会凭空推断。
- 手动分组作用于全部勾选项（含搜索隐藏项），重新载入数据后重置；线路图 JSON 记录分组与布局信息，不修改游戏存档。
- 修复短小补偿台阶、共线眼形回环、部分弯道尖折，以及 Union 等站点附近路径重叠折返。
- 修复 metroTopology 未定义及绘图依赖加载问题；静态资源按内容版本更新，缺失资源明确报错。
- 线路列表新增名称 / 编号 / 站名搜索和 A–Z、Z–A、站数、编号、已选优先排序。

操作体验与可靠性
- 明确“核对存档与游戏导出”需要玩家先在游戏内导出时刻表数据，区分工具箱线路图 JSON。
- 更新首次教学、教程、帮助说明及错误提示，说明功能边界和下一步操作。
- 修正按目标班距计算最低列车数时的向上取整，并拒绝无效高峰时间设置。
- 工具副本可手动设为保留；清理需核验生成记录与文件哈希，已被玩家再次保存或无法验证的副本不自动清理。
- 清理预览过期时停止操作并要求重新预览；更新失败分别说明未安装、已恢复及恢复不完整。

升级说明
- Windows x64 零基础 EXE 包内置 Python、Node.js 和桌面组件，无需另外安装，不弹出终端窗口。
- 已有更新按钮的便携版可点击“检查更新”，确认后下载并重启；启动自动检查可能受 6 小时缓存影响，手动检查可立即刷新。
- 下载和安装继续校验 SHA-256 与逐文件清单。程序更新不覆盖游戏存档、个人设置或导出数据。
- Git 源码工作区不会被自动覆盖；本版未改变自动铺轨仍需游戏内接轨、信号与验收的限制。
