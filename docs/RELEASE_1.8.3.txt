NIMBY Timetable Toolkit 1.8.3

自动铺轨：部分区间失败也能保留可用蓝图
- 多站线路按相邻站点逐段检查；部分区间失败时，可勾选“仅生成通过区间”，生成包含合格区间蓝图的新测试存档。
- 例如 A→B 和 C→D 通过、B→C 失败，保留前后两段，B→C 留空，不会跨越失败区间自动补连。
- 预览显示各区间检查结果和失败原因；生成清单记录成功与跳过的区间，方便回到游戏中处理缺口。
- 部分生成需要单独确认；修改生成设置后清除确认并要求重新预览。
- 明确区分“删除站点后重新寻路”和“跳过失败区间”；更新首次教学和操作说明。

保留安全检查
- 全部区间失败时不生成；源存档、底图或成功区间与预览不一致时停止写入。
- 保留存档结构、轨道冲突、桥隧及总规模检查，不把未知存档结构或底图中途变化当成可跳过的局部失败。
- 只写新测试存档，不覆盖输入存档。生成后请在游戏内检查轨道连接、净空、坡度和运营条件。
- 本功能按相邻站点之间的完整区间跳过，不会自动切碎单个失败区间；可增加途经点或调整搜索范围后重新预览。
- “导出预览方案”仍是 JSON 报告；可在游戏中加载的蓝图位于新生成的测试存档中。

升级说明
- 继续提供 Windows x64 免安装 EXE 包，内置 Python、Node.js 和桌面组件。
- 已有更新按钮的便携版可点击“检查更新”，确认后下载并重启；手动检查不受启动检查的 6 小时缓存限制。
- 更新校验 ZIP SHA-256 与逐文件清单，不覆盖游戏存档、个人设置或导出数据。
